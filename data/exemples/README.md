# Exemples de relevés

Un relevé réel, conservé tel quel pour montrer le format de sortie de la collecte. Les relevés courants
sont écrits dans `data/brut/` (hors dépôt) et archivés par l'action GitHub « Collecte hebdomadaire ».

Chaque ligne est un produit vu sur une page de catégorie d'un site concurrent : date du relevé, site,
page lue, titre, prix actuel, prix initial s'il y a une promotion, adresse du produit.
